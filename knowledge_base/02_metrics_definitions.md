# NovaMed 销售指标口径

## 核心指标

| 指标 | 定义 |
| --- | --- |
| 净签约套数（units） | 当周完成签约并确认交付的套数，已经扣除同周退订。它不是线索数，也不是累计装机量。 |
| 实际成交单价（unit_price_cny） | 目录价乘以一减折扣率，按百元取整。 |
| 销售额（revenue_cny） | 净签约套数 × 实际成交单价。金额为人民币，不含预测机会金额。 |
| 目标销售额（target_revenue_cny） | 区域、机构、产品、周粒度的经营目标。 |
| 目标达成率 | 销售额 ÷ 目标销售额。汇总时先分别求和，再相除，不能直接平均行级百分比。 |
| 平均成交单价 | 销售额 ÷ 净签约套数。净签约套数为零时结果为不适用。 |
| 退订数（returns） | 当周确认退订的套数，用于风险监控。units 已经扣除退订，不应再次从销售额中扣减。 |

## 漏斗指标

漏斗顺序是拜访（visits）→ 演示（demos）→ 试用（trials）→ 转签（conversions）。每条周记录满足拜访数不低于演示数，演示数不低于试用数，试用数不低于转签机构数。

- 演示率 = 演示数 ÷ 拜访数。
- 试用转签率 = 转签机构数 ÷ 试用机构数。
- 漏斗比率在汇总层面必须使用汇总后的分子与分母计算。

## 时间与排名

- 周从星期一开始，到星期日结束。
- “最近四周”指数据集中最后四个完整周，不包括未来周。
- 机构或区域排名默认按销售额降序；销售额相同时按稳定标识符升序。
- 除非提问另有说明，经营汇总使用完整数据期2026-07-06至2026-08-30。
