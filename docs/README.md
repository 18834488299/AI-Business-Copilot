## 项目定位

这是一个面向商业分析场景的 evidence-grounded AI Agent。它不是“给大模型套一层聊天页面”，而是把一个业务问题拆成可观察的执行过程：

`理解问题 → 选择工具 → 查询结构化数据/知识库 → 汇总证据 → 生成结论 → 返回引用与 trace`

项目同时提供本地确定性模式和可选模型模式。本地模式不需要 API Key，便于招聘方复现；模型模式用于展示真实工具调用与自然语言综合能力。

## 文档口径

- “事实”指演示数据或演示知识库中的内容，不代表任何真实企业。
- “准确率”“延迟”等数字只有在一次具体评测报告中才应作为结果引用，不在项目介绍中预设夸大数值。
- trace 指可审计的路由、检索与工具执行记录，不包含也不声称展示模型的私有思维过程。
